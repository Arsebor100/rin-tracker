Настройка синхронизации

Прогресс хранится в приватном GitHub Gist и синхронизируется между устройствами. Токен остаётся только в этом браузере.

Как получить токен (1 минута)
  1. Открой github.com/settings/tokens/new
  2. Note: rin-tracker
  3. Expiration: No expiration
  4. Scopes: отметь только gist
  5. Generate token → скопируй ghp_...
Токен нужен только для доступа к твоим гистам. Не показывай его никому.
